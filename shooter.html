This is a 3D action game where you control a soldier and fight waves of enemies. I initially built it as a stealth game, but I found the moments of action when you get caught more fun than the sneaking.

Although programming most of the systems was quite straight forward, I eventually stopped working on this because I found Unity's Navigation package was too limited to build smart enemy behaviour with.

If I wanted smart enemies I would have to reimplement navmeshes, pathfinding, and lots of other things from scratch, and I found that time would be better spent working on new projects.

I also built some of the 3D models used in this game.
